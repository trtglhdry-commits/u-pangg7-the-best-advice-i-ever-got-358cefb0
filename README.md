## How it works

`main.ts` (Node 22, stdlib only) writes the line above to `/output/entry.txt` (override with `OUTPUT_DIR`). It is fully deterministic — no randomness, no network, no clock — and the line passes the competition gate: a single sentence of 1–200 characters, not only white space.

Run it with:

